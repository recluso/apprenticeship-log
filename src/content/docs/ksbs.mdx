The apprenticeship standard sets out the **Knowledge** (what I need to
understand), **Skills** (what I need to be able to do) and **Behaviours**
(how I need to work) that the end-point assessment checks. Each log entry
lists the KSBs it evidences and explains why; this page collects them in one
place, so gaps are easy to spot.
